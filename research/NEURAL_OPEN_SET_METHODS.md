# Neural open-set comparison — frozen implementation choices

Three methods: ordinary cross-entropy CNN, single-branch prototype-learning (PL) baseline, and two-branch PredIN. All use the existing3-convolution compact encoder, followed by linear64→128 embedding, on the fixed known-only GRABMyo protocol. PredIN is an equation-based adaptation of arXiv2407.19753v2, not an original paper numerical reproduction. Author code was not located. Published journal record: https://pubmed.ncbi.nlm.nih.gov/41576776/ ; versioned manuscript: https://arxiv.org/html/2407.19753v2 . Local source snapshot: research/literature/predin_2407_19753v2/.

Prototype probabilities use raw dot products and cross-entropy. Compactness follows Eq5 literally: for each embedding-minus-positive-prototype vector, half L2 norm if its L1 norm<1, otherwise L1 norm−0.5; then average samples. This unusual printed expression is not silently changed to coordinatewise smooth-L1 or squared L2. No L2 normalization is added. Triplet uses nearest incorrect prototype by Euclidean distance, margin1. Inconsistency follows Eqs8–10, masks the true class, detaches the positive similarity, and uses margin0.5. Sum per-branch classification/compactness/triplet terms and add the shared inconsistency once, all weights1. Primary PL/PredIN rejection uses maximum raw similarity, with PredIN averaging raw similarities across branches before argmax/thresholding. Maximum softmax is also saved as a control. CNN uses maximum softmax.

Project-specific training choices: seed42 (branch2seed43), Adam with20pretrainingepochs/20enrollmentepochs at.001,10targetupdateepochs at.0001, batch128. These retain the existing project's training schedule, differing from paper SGD/100epochs and its larger backbones. Compare methods at this fixed schedule, not claim all are optimally converged. Save losses/checkpoints to assess limitations. No outcome-based hyperparameter selection. No new algorithm claim.
